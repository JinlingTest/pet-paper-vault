## Daily Worksheet Format

Each daily worksheet should include:

1. Printable student paper
2. Answer key
3. Simulated wrong student answers
4. Bilingual teacher explanation
5. Color marking:
   - red = wrong student answer
   - green = correct answer
   - blue = English explanation
   - brown = Chinese explanation
   - purple = key word or easily confused point
6. One small creative extension when useful, such as:
   - error tags
   - oral retelling task
   - mini writing task
   - collocation challenge
   - "teach the word to a friend" prompt
